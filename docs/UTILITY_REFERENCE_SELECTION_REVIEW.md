# Utility reference selection: practical review

25 October 2026. Public evidence review, not an exhaustive ranking of NSW towns. Preserve Menindee electricity, Orange water and Narromine sewerage working anchors. The separate Dubbo water engineering example is complementary, not a replacement decision.

| Utility | Working recommendation | Evidence boundary |
|---|---|---|
| Electricity | Menindee with wider Far West references | Existing NSW-ELEC evidence governs; regional generation is not asserted inside Menindee. |
| Water | Orange | Manus comparison retained; no fully open SCADA/street pipe model established. |
| Sewer | Narromine | Existing PIRMP/annual report evidence; installed reuse infrastructure is not proof of active reuse. |
| Gas | Narromine provisional; compare Wagga distribution | APA names Narromine as a Central West Pipeline delivery. Wagga has publicly documented distribution/regulatory history; neither establishes publicly mapped household pipes. |
| Fixed internet/phone, mobile, broadcasting | Orange provisional; evaluate as separate services | National NBN/ACMA data support all towns; they do not demonstrate Orange uniquely has richest evidence or measured address performance. |
| Waste/recycling/organics | Orange strong candidate | Council publishes baling, transfer, compost tunnel and landfill descriptions and an independent environmental audit. |
| Fuel | Dubbo retail case, Newcastle upstream comparator | FuelCheck gives retail prices; terminal planning/EIS material can inform upstream storage, not prove a Newcastle-to-Dubbo supply route. |

Selection acceptance: demonstrate a source-to-building boundary, demand data/defensible assumptions, operating dependencies and a reproducible failure/restoration scenario. Use complementary specialist references without mixing separate towns into an asserted real network.
